# Changelog

Формат версий `x.x.xx`: минор — новый функционал, патч — исправления и доработки.

## 1.2.00 — 2026-11-15

Объединение с параллельной веткой `claude/exciting-franklin-rmdaus`: взяты только
исправления, которых не было в проде; инфраструктура 1.1.00 не менялась.

- **Новое:** форма сохранения и удаления ключа TMDB на странице `/tmdb`
  (нужен `ADMIN_TOKEN`); `/api/tmdb/status` сообщает `canManage`.
- **Исправлено:** страницы фестивалей (Канны, Венеция, Берлин и др.) в markdown-режиме —
  категории с иконкой, списки «Участники…», победители без постера, «Имя — Фильм».
  Раньше такие страницы отвечали «формат страницы не распознан».
- **Исправлено:** ZIP галереи IMDb не освобождал слот после успешного скачивания —
  после двух архивов все следующие получали 503 до перезапуска.
- ZIP начинает отдаваться после первой страницы галереи, остальные догружаются по ходу;
  некорректный id не расходует лимит запросов; обрыв клиента прерывает загрузки.
- IMDb: сбой на середине постраничной загрузки даёт помеченный неполный результат
  (кэш 10 минут) вместо ошибки; полный кэш неполным не затирается.
- Кэш отчётов: отчёт, снятый после года премии, считается итоговым и больше не
  перекачивается (раньше прошлогодние отчёты обновлялись каждые 7 дней).
- Тесты на реальных страницах-фикстурах, ZIP и IMDb: 28 кейсов.

## 1.1.00 — 2026-08-31

- Версионированные SQL-миграции с контрольными суммами (`migrations/`, `app_migrations`).
- Ежедневный `pg_dump` сервисом `backup` с ротацией.
- Отдельная роль БД, секреты в `.env`, изолированная внутренняя сеть, read-only
  контейнеры без capabilities и с лимитами ресурсов, приложение не от root.
- Лимиты запросов, admin API по `ADMIN_TOKEN`, метрики `/api/metrics`, JSON-логи.
- Очередь внешних запросов с объединением одинаковых; таймауты и повторы IMDb/Jina.
- Сканирование: отсутствие страницы фиксируется только при подтверждении, сбой — `error`.
- Сопоставление фильма по id Кинопоиска и названию; правила свежести кэша.
- `robots.txt`, `sitemap.xml`, манифест, иконки, фокус в диалогах; CI.

## 1.0.00 — 2026-07

- Первый запуск: Next.js 16 + PostgreSQL 16, отчёты по премиям Кинопоиска, IMDb и TMDB.

# 🏆 Кинонаграды (Desktop) — GUI-приложение на Python

Автономное настольное приложение — полный аналог веб-версии сервиса
«Кинонаграды»: IMDb, Кинопоиск и TMDB в одном окне с вкладками.
Работает на любом ПК с Python (Windows, macOS, Linux) без сервера и БД.

## Возможности (паритет с веб-версией)

| Функция | Веб | Python |
|---|---|---|
| IMDb: поиск фильма → все награды (победы выделены) | ✅ | ✅ вкладка «IMDb» |
| IMDb: персона → полная фильмография (⭐) | ✅ | ✅ окно персоны |
| IMDb: событие → все номинанты церемонии (🎪, GraphQL) | ✅ | ✅ окно события |
| Кинопоиск: отчёт о премии по URL | ✅ | ✅ вкладка «Отчёт о премии» |
| Кинопоиск: поиск фильма по 24 премиям × 3 года | ✅ | ✅ вкладка «Поиск фильма» |
| TMDB: поиск (русские названия) → переход к наградам IMDb | ✅ | ✅ вкладка «TMDB» |
| TMDB: вставка/проверка/удаление ключа в интерфейсе | ✅ | ✅ (хранится в settings.json) |
| Экспорт Markdown с Telegram tags (🔸/🔹, #Persons, Name/Year/Storiline/Cast) | ✅ | ✅ |
| Экспорт HTML (один автономный файл, тёмная тема) | ✅ | ✅ |
| Экспорт XLSX (автоширина, перенос строк, автофильтры, победы золотом) | ✅ | ✅ (нужен openpyxl) |
| Устойчивость к лимитам API (ретраи 429/5xx, паузы, частичные результаты) | ✅ | ✅ |
| Кэширование | PostgreSQL | локальные json-файлы (`cache/`) |

Небольшие отличия: XLSX содержит 2 листа вместо 3–4 (без листа «Персоны»),
отчёты Кинопоиска строятся из markdown-версии страницы (состав номинаций
может отличаться на пару позиций от HTML-версии).

## Требования

| Компонент | Версия |
|---|---|
| Python | 3.10 или новее |
| tkinter | входит в стандартную поставку Python* |
| Интернет | доступ к imdb.com, api.imdbapi.dev, api.graphql.imdb.com, r.jina.ai, themoviedb.org |
| openpyxl | *опционально*, только для экспорта XLSX |

\* Linux: `sudo apt install python3-tk` (Debian/Ubuntu) или
`sudo dnf install python3-tkinter` (Fedora).

## Установка и запуск

```bash
cd python-prj

# (рекомендуется) виртуальное окружение
python -m venv .venv
# Windows:  .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# (опционально) для XLSX-экспорта
pip install -r requirements.txt

python main.py
```

## Как пользоваться

### Вкладка «IMDb: награды фильма»
1. Введите название → **Найти** → двойной клик по фильму
2. Дерево «событие → номинации»: победы золотым, события с победами раскрыты
3. **Двойной клик по событию** (строка 🎪) — окно со **всеми номинантами
   церемонии** по категориям; двойной клик по фильму там — его награды
4. **Двойной клик по номинации** — окно персоны (⭐): фото-факты,
   полная фильмография; двойной клик по работе — её награды
5. Экспорт: 💾 Markdown / HTML / XLSX

### Вкладка «Кинопоиск: отчёт о премии»
Вставьте ссылку вида `https://www.kinopoisk.ru/awards/oscar/2026/` (или кнопки-
примеры) → дерево категорий с победителями → экспорт MD/HTML/XLSX.

### Вкладка «Кинопоиск: поиск фильма»
Название + год выпуска → сканирование 72 страниц премий (прогресс-бар, 3 потока).
Первый скан года — несколько минут, повторные — мгновенны (кэш в `cache/kp/`).
Результат: победы и номинации по каждой премии + экспорт.

### Вкладка «TMDB»
1. Один раз вставьте бесплатный ключ ([themoviedb.org → Settings → API](https://www.themoviedb.org/settings/api)) —
   принимаются и v3 Key, и v4 Token; ключ проверяется живым запросом
2. Ищите по русским названиям → двойной клик → автоматический переход
   на вкладку IMDb с наградами

## Структура проекта

```
python-prj/
├── main.py               # точка входа: python main.py
├── requirements.txt      # опционально: openpyxl
├── settings.json         # создаётся автоматически (ключ TMDB)
├── cache/kp/             # кэш страниц Кинопоиска (json)
└── app/
    ├── imdb_api.py       # IMDb: поиск, награды, персоны, события (GraphQL)
    ├── kinopoisk_api.py  # Кинопоиск: отчёты, сканирование премий, кэш
    ├── tmdb_api.py       # TMDB: ключ, поиск, резолв в IMDb ID
    ├── exporters.py      # MD (+Telegram tags), HTML, XLSX для всех модулей
    ├── gui.py            # окно, вкладка IMDb, окна персоны/события
    ├── gui_kp.py         # вкладки Кинопоиска
    └── gui_tmdb.py       # вкладка TMDB
```

Модули данных не зависят от GUI — их можно использовать в своих скриптах:

```python
from app import imdb_api, kinopoisk_api, exporters

report = kinopoisk_api.fetch_report("oscar", 2026)
print(exporters.kp_report_markdown(report))

edition = imdb_api.fetch_event("ev0000003", 2025)   # все номинанты Оскара-2025
matches = kinopoisk_api.scan_film("Грешники", 2025) # поиск по 24 премиям
```

## Устранение неполадок

| Проблема | Решение |
|---|---|
| `ModuleNotFoundError: tkinter` | установите python3-tk вашего дистрибутива |
| Кнопка XLSX просит openpyxl | `pip install openpyxl` |
| «HTTP 429» в статусе | лимит API IMDb: приложение само повторяет с паузами; большие персоны/фильмы грузятся до минуты |
| Кинопоиск: «Нет данных» | страницы премии за этот год не существует; промах кэшируется на сутки |
| TMDB: «ключ отклонён» | скопируйте ключ целиком со страницы Settings → API |
| Медленный первый скан премий | нормально: 72 страницы через прокси; далее кэш |
